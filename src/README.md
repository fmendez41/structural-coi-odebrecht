# Analysis code

Standalone Python scripts and the shared `coi_lib.py` library supplied in the reproducibility ZIP. Only repository-relative paths were updated.

`extract_notebook_provenance.py` statically audits active `add_edge` statements in the supplied construction notebooks and compares declared compositions with deposited GEXFs. `inventory_source_archive.py` creates a hash-based archive inventory without extracting or redistributing third-party documents.
