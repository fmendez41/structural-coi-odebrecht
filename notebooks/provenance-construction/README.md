# Original network-construction notebooks

These 16 notebooks are preserved byte-for-byte from `N1Ref.zip`. They contain the historical Python/NetworkX construction work, including many edge-level comments and bibliography tokens.

`H1N1-Master1-ALLTIMES2022Noviembre.ipynb` is the newest supplied master notebook by filename and is the only one that declares the `G1`-`G4`/`GALLTIMES` compositions and GEXF writes. It is therefore the best available reconstruction entry point, but it is not an exact recipe for every currently deposited GEXF: the active statements differ from the final files by a small-to-material number of edges depending on the period. See `data/provenance/notebook_reconstruction_audit.csv`.

The notebooks are historical research artifacts. They have not been reformatted, executed, or edited. The repository-level extraction script performs static analysis so that provenance can be audited without executing notebook cells or changing the scientific networks.
