# Provenance status

The supplied ZIP did not contain a complete edge-level provenance file. No rows have been inferred or invented.

The supplied documentation identifies the two v2 event nodes and seven added institutional edges as anchored in the 2019 electoral-nullity petition, but it does not provide a source document, page, date, and note for every network edge.

A future `edges_provenance.csv` should be added only from verified source records. A useful schema would include source node, target node, relation type, period, source document, locator/page, source date, and notes. This suggested schema is not evidence and is not included as data.
